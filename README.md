جدول رتبه‌بندی درس ساختمان داده، به سبک جدول لیگ فوتبال. هر دانشجو با باز کردن سایت در چند ثانیه می‌بیند:

- رتبه‌اش در جدول کلی و در هر تمرین چند است
- چند امتیاز دارد
- نسبت به قبل چند پله بالا یا پایین رفته
- چقدر با جمع ۱۲ نفر برتر فاصله دارد

سایت برای موبایل طراحی شده و مستقیم از لینک تلگرام باز می‌شود.

## راهنمای خواندن جدول

| نشانه | معنی |
|:---:|---|
| **▲ ۲** | دو پله صعود نسبت به جدول قبل |
| **▼ ۱** | یک پله سقوط |
| **—** | بدون تغییر |
| 🟢 ⚪ 🔴 | فرم ۵ تمرین اخیر: بالای کلاس، میانه، پایین کلاس |

- تب **مجموع** رتبه‌بندی بر اساس جمع همه تمرین‌ها و پروژه‌هاست. هر تب دیگر فقط همان تمرین را نشان می‌دهد.
- در «مجموع»، تغییر رتبه نسبت به جدولِ قبل از آخرین تمرین حساب می‌شود. در هر تمرین، نسبت به تمرین قبلی.
- اسمتان را در کادر جستجو بنویسید تا ردیفتان پیدا و برجسته شود.
- روی هر ردیف بزنید تا نمره و رتبه آن نفر در همه تمرین‌ها باز شود.
- لینک مستقیم هر تب: [`#total`](https://alizn7.github.io/DS-ScoreBoard/#total)، [`#hw0`](https://alizn7.github.io/DS-ScoreBoard/#hw0)، [`#hw1`](https://alizn7.github.io/DS-ScoreBoard/#hw1)، …

## نمره لیگ

نمره‌ی هر دانشجو بر اساس رتبه‌ی او در جدول لیگ به شکل زیر محاسبه می‌شود:

| رتبه | ضریب | نمره |
|---|:---:|:---:|
| 🥇 نفر ۱ و ۲ | ۱۰۰٪ | **۳** |
| 🥈 نفر ۳ و ۴ | ۹۰٪ | **۲٫۷** |
| 🥉 نفر ۵ و ۶ | ۷۵٪ | **۲٫۲۵** |
| نفر ۷ و ۸ | ۵۵٪ | **۱٫۶۵** |
| نفر ۹ و ۱۰ | ۴۵٪ | **۱٫۳۵** |
| نفر ۱۱ و ۱۲ | ۳۵٪ | **۱٫۰۵** |

جزئیات چک‌پوینت اول و دوم بعداً در [سایت](https://alizn7.github.io/DS-ScoreBoard/#guide) اعلام می‌شود.

## برای دستیارهای آموزشی

### ساختار پروژه

```
docs/
├── index.html    صفحه اصلی
├── style.css     ظاهر سایت
├── app.js        خواندن CSV، رتبه‌بندی، نمایش
├── config.js     عنوان درس، جدول نمره لیگ، چک‌پوینت‌ها
└── scores.csv    نمره‌ها — تنها فایلی که هر بار عوض می‌شود
```

سایت کاملاً استاتیک است و از شاخه `main`، پوشه `/docs` روی GitHub Pages منتشر می‌شود. سرور، دیتابیس یا build لازم ندارد.

### به‌روزرسانی نمره‌ها

1. در گوگل‌شیت، تبی که فقط این ستون‌ها را دارد باز کنید:
   ```
   نام | تمرین ۰ | تمرین ۱ | … | پروژه ۱ | …
   ```
2. از مسیر File → Download → **Comma Separated Values (.csv)** دانلود کنید.
3. فایل را با اسم `scores.csv` جایگزین `docs/scores.csv` کنید.
4. commit و push کنید:
   ```bash
   git add docs/scores.csv
   git commit -m "Update scores: تمرین ۱"
   git push
   ```

سایت معمولاً ظرف یکی دو دقیقه به‌روز می‌شود. «آخرین بروزرسانی» زمان آخرین commit روی `scores.csv` است، پس push کردن فایل‌های دیگر آن را عوض نمی‌کند.

### قواعد فایل CSV

- **ستون اول** همیشه اسم دانشجوست. عنوان بقیه ستون‌ها اسم تب‌های سایت می‌شود. تمرین یا پروژه جدید فقط یک ستون جدید است.
- ستونی که همه خانه‌هایش **خالی یا صفر** باشد هنوز نمره نخورده حساب می‌شود و در سایت «به‌زودی» نشان داده می‌شود.
- وقتی در ستونی حتی یک نمره غیرصفر باشد، آن ستون نمره‌خورده است. در این حالت ۰ همان ۰ است و خانه خالی هم ۰ حساب می‌شود.
- عدد فارسی یا انگلیسی و اعشار با `.` یا `٫` هر دو قبول است.
- «مجموع» جمع خام ستون‌هاست. اگر مقیاس تمرین و پروژه فرق دارد، قبل از خروجی گرفتن نمره‌ها را هم‌مقیاس کنید.
- اسم‌ها باید یکتا باشند.

### تنظیمات — `docs/config.js`

| کلید | کاربرد |
|---|---|
| `course`، `year` | عنوان بالای صفحه |
| `topSize` | تعداد نفرات بخش برتر (پیش‌فرض ۱۲) |
| `repo` | اسم ریپو، برای خواندن زمان آخرین به‌روزرسانی نمره‌ها |
| `leaguePoints` | جدول نمره لیگ در بخش راهنما |
| `checkpoints` | چک‌پوینت‌ها. تا وقتی `points: null` است، «به‌زودی اعلام می‌شود» نمایش داده می‌شود. `date` و `note` اختیاری‌اند. |

مثال:
```js
{title: "چک‌پوینت اول", points: 0.25, date: "۱۵ آبان", note: "بر اساس جدول مجموع در این تاریخ"}
```

### ⚠️ حریم خصوصی

این ریپو عمومی است و هر فایلی که یک‌بار push شود در تاریخچه git باقی می‌ماند.

- **هیچ‌وقت** خروجی کامل شیت اصلی را push نکنید. ستون‌هایی مثل ضریب تقلب، تسلط، کامنت و شماره دانشجویی نباید وارد ریپو شوند.
- `scores.csv` فقط باید اسم و نمره نهایی هر تمرین را داشته باشد. قبل از هر commit یک نگاه به آن بیندازید.
- فایل‌های `.xlsx` و `.ods` در `.gitignore` هستند، ولی CSV نیست.

### اجرای محلی

```bash
cd docs
python3 -m http.server
```

سپس `http://localhost:8000` را باز کنید. باز کردن مستقیم `index.html` کار نمی‌کند، چون مرورگر اجازه خواندن CSV از روی دیسک را نمی‌دهد.
